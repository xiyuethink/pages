| 文件 | 用途 |

## 如何使用

### 在 GitHub 直接浏览

点击上方的文件链接，即可在 GitHub 上查看渲染效果。

### 通过 GitHub Pages 访问

启用 GitHub Pages 后，可通过以下地址访问：

```
https://xiyuethink.github.io/pages/tests/test
https://xiyuethink.github.io/pages/tests/
```

如果页面能正常显示，说明部署成功。

## 验证清单

- [ ] 可以通过 GitHub 浏览 `test.md` 文件

- [ ] 可以通过 Pages URL 访问测试文件
- [ ] 所有 Markdown 元素渲染正常（标题、列表、代码、表格、引用）
